# CybrLoop Brand System (نظام هوية CybrLoop)

## 1. Brand Identity (هوية العلامة)

CybrLoop is a cybersecurity team focused initially on application security.

Current category descriptor:

> Application Security for Product Teams.

CybrLoop starts with application security and is intended to grow into a broader cybersecurity services company as real team capabilities are developed.

The brand should communicate:

- Technical competence
- Precision
- Clarity
- Collaboration
- Practical security
- Continuous improvement

CybrLoop should feel like a capable technical partner, not an intimidating security vendor.

---

## 2. Core Brand Idea (الفكرة الأساسية للعلامة)

Security should be:

- Actionable
- Understandable
- Collaborative

Official slogan:

> Secure the Loop.

Primary positioning message:

> Making security actionable, understandable, and collaborative.

Supporting positioning statement:

> We help product teams understand, act on, and improve security — not just find vulnerabilities.

Short marketing message:

> Making security actionable.

This short message may be used selectively as a marketing headline, but it is not the official slogan.

---

## 3. Personality (شخصية العلامة)

CybrLoop should feel:

- Technical
- Calm
- Precise
- Modern
- Structured
- Curious
- Collaborative
- Confident

CybrLoop should NOT feel:

- Aggressive
- Corporate-heavy
- Hacker-themed
- Fear-driven
- Mysterious for the sake of being mysterious
- Flashy
- Gaming-oriented
- Crypto-oriented

The tone should communicate competence without arrogance.

---

## 4. Visual Direction (الاتجاه البصري)

Adopted direction:

# Structured Technical Minimalism (بساطة تقنية منظمة)

The visual system should combine:

- Minimal layouts
- Strong spacing
- Clear hierarchy
- Technical geometry
- Structured grids
- Fine lines
- Controlled visual detail
- A single strong accent color

The result should feel engineered rather than decorated.

---

## 5. Color Palette (لوحة الألوان)

### Deep Black (أسود عميق)

`#0B0D0D`

Primary website background.

### Charcoal (فحمي)

`#1A1A1E`

Secondary surfaces, cards, navigation, and elevated sections.

### Slate (رمادي أردوازي)

`#3A3A40`

Borders, secondary UI elements, subtle separators.

### Cloud (رمادي فاتح)

`#D7D7DB`

Secondary text.

### White (أبيض)

`#FAFAFB`

Primary text and high-contrast content.

### Signal Orange (برتقالي إشاري)

`#FF7A1A`

Primary accent color.

Use Signal Orange intentionally.

It may be used for:

- Important words
- Calls to action
- Small indicators
- Active states
- Diagram markers
- Technical highlights
- Selected borders
- Small glow effects

Do not cover large portions of the interface in orange.

---

## 6. Color Rules (قواعد الألوان)

Prefer dark interfaces.

Approximate visual balance:

- 70–80% dark neutrals
- 15–25% white and grey content
- 5% or less Signal Orange

Do not introduce additional strong accent colors without explicit approval.

Avoid:

- Neon green
- Bright cyber blue
- Purple cyberpunk gradients
- Rainbow gradients
- Excessive orange glow

---

## 7. Typography (الخطوط)

Preferred typefaces:

1. Geist
2. Inter

Use clean sans-serif typography.

Typography should rely on:

- Scale
- Weight
- Spacing
- Alignment

rather than decorative fonts.

Headlines should feel modern and strong without becoming excessively bold.

Body text should prioritize readability.

Technical labels may use:

- Uppercase
- Increased letter spacing
- Smaller font sizes

when appropriate.

Do not overuse this treatment.

---

## 8. Layout Principles (مبادئ التخطيط)

Use generous negative space.

Prefer:

- Clear sections
- Consistent spacing
- Strong grid alignment
- Controlled asymmetry
- Structured layouts
- Large typography where appropriate

Avoid filling every empty area.

Whitespace is part of the visual identity.

---

## 9. Graphic Language (اللغة الرسومية)

Approved visual elements include:

- Thin technical lines
- Grid systems
- Small dots
- Coordinates
- Geometric forms
- Technical diagrams
- Blueprint-like structures
- Small Signal Orange markers
- Large translucent CybrLoop logo shapes
- Subtle texture
- Controlled glow
- Abstract system diagrams
- Connection paths
- Loop-inspired geometry

Visuals should suggest:

- Systems
- Structure
- Analysis
- Connections
- Flow
- Security engineering

rather than generic hacking.

---

## 10. CybrLoop Logo Usage (استخدام شعار CybrLoop)

The logo may be used as:

- Primary brand mark
- Small navigation mark
- Social profile image
- Large translucent background graphic
- Technical decorative element

When used decoratively:

- Lower opacity
- Large scale
- Partial cropping is acceptable

Do not distort the logo.

Do not apply random gradients.

Do not add unnecessary effects.

---

## 11. Imagery Rules (قواعد الصور)

Prefer abstract or technical graphics over stock photography.

Avoid generic cybersecurity imagery such as:

- Hooded hackers
- People wearing masks
- Glowing locks
- Binary rain
- Matrix visuals
- Anonymous silhouettes
- Green terminals
- Random code screenshots
- Padlocks floating over servers

If photography is used later, it should feel natural and technical rather than staged.

---

## 12. UI Style (أسلوب الواجهة)

Interface elements should be:

- Minimal
- Geometric
- Clear
- Functional

Buttons should use simple shapes.

Avoid excessive rounding.

Preferred border radius:

- Small to medium

Cards should not look like generic SaaS template cards.

Use cards only when they improve information structure.

Borders should generally be subtle.

Example:

`1px solid #3A3A40`

Use shadows sparingly.

---

## 13. Motion (الحركة)

Motion should communicate refinement, not spectacle.

Allowed:

- Small fade-ins
- Subtle reveals
- Minor transforms
- Soft line movement
- Slow technical background motion
- Button feedback
- Navigation transitions

Avoid:

- Heavy parallax
- Constant animation
- Large glowing effects
- Excessive scroll hijacking
- Long cinematic intros

Animations must never delay access to information.

---

## 14. Tone of Voice (نبرة التواصل)

Writing should be:

- Clear
- Direct
- Technical
- Concise
- Human
- Professional

Prefer:

> We identify security risks and help your team understand what to do next.

Avoid:

> We leverage cutting-edge next-generation cybersecurity solutions to provide unparalleled protection.

Do not use fear as a sales technique.

Avoid language such as:

- Hackers are coming
- Your business is at risk
- Protect yourself before it's too late
- Military-grade security
- Unbreakable
- Bulletproof
- 100% secure

Security communication should focus on understanding and improvement.

---

## 15. Messaging Hierarchy (ترتيب الرسائل)

Use this primary brand hierarchy consistently:

### Brand

CybrLoop

### Slogan

Secure the Loop.

### Descriptor

Application Security for Product Teams.

### Positioning message

Making security actionable, understandable, and collaborative.

When developing supporting public CybrLoop material, prioritize:

### 1. Problem

Product teams need security expertise that integrates with development.

### 2. Approach

Understand → Assess → Prioritize → Collaborate → Improve.

### 3. Outcome

Clear security findings that teams can act on.

### 4. Capability

Application security assessment.

### 5. Community

Research, tools, talks, projects, and competitions.

Do not lead with a large list of security services.

---

## 16. Brand Consistency Rules (قواعد اتساق العلامة)

Every new design should be checked against these questions:

1. Does it feel technical?
2. Does it feel structured?
3. Is it visually calm?
4. Is Signal Orange used intentionally?
5. Is the content easy to understand?
6. Does it avoid cybersecurity clichés?
7. Does it look like CybrLoop rather than a generic cybersecurity template?

If the answer to several of these is no, revise the design.

---

## 17. Design Priority (أولوية التصميم)

When choosing between visual complexity and clarity:

Choose clarity.

When choosing between decoration and structure:

Choose structure.

When choosing between more elements and more whitespace:

Prefer whitespace.

When choosing between a generic cybersecurity visual and an abstract technical CybrLoop visual:

Choose the CybrLoop visual.
