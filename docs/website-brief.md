# CybrLoop Website Brief (موجز موقع CybrLoop)

## 1. Project Overview (نظرة عامة على المشروع)

CybrLoop is a cybersecurity team currently focused on application security.

We work with startups and growing companies that build digital products, especially teams that have active development capabilities but limited or no dedicated internal security team.

CybrLoop helps these teams identify security risks, understand their real impact, prioritize what matters, and turn security findings into clear and actionable improvements in collaboration with development teams.

CybrLoop is not positioned only as a pentesting vendor.

The long-term direction is to become a broader cybersecurity services company, while building each service only when the team has the practical capability to deliver it properly.

The public identity of CybrLoop also includes:
- Technical content
- Security research
- Open-source tools
- Talks and workshops
- Competitions
- Community participation
- Technical projects

The website should represent both sides:
1. Professional cybersecurity services
2. Technical and community involvement

---

## 2. Website Goal (هدف الموقع)

This is the first public version of the CybrLoop website.

The goal is NOT to build a large corporate website.

The goal is to create a small, professional, credible public presence that can be shared with:

- Potential clients
- Startup founders
- Development teams
- Event organizers
- Security communities
- Competition organizers
- Technical collaborators

A visitor should understand within approximately one minute:

1. What CybrLoop is
2. Who CybrLoop works with
3. What CybrLoop currently does
4. How CybrLoop approaches security
5. How to contact CybrLoop

---

## 3. Primary Audience (الجمهور الأساسي)

### Primary audience

Startups and growing companies that:

- Build web applications or digital products
- Have an internal development team
- Do not have a dedicated security team
- Treat security as a secondary responsibility
- Need external security expertise without hiring a full internal security function

### Secondary audience

- Software engineers
- Security researchers
- Students
- Technical communities
- Conference and event organizers
- Potential future team members or collaborators

---

## 4. Positioning (التموضع)

CybrLoop should feel like a technical security partner, not a company that simply runs a scan, sends a PDF, and disappears.

Core idea:

> We help product teams understand, act on, and improve security — not just find vulnerabilities.

The CybrLoop approach is based on:

### Actionable Security (أمن قابل للتنفيذ)

Security findings should lead to clear next steps.

### Understandable Security (أمن مفهوم)

Reports and discussions should clearly explain impact, risk, and priority without unnecessary complexity.

### Collaborative Security (أمن تعاوني)

CybrLoop works with development teams instead of operating as a disconnected external security function.

## 6. Current Primary Service (الخدمة الأساسية الحالية)

The first commercial service is:

# Web Application Security Assessment (تقييم أمن تطبيقات الويب)

The service focuses on identifying and understanding security weaknesses in web applications and their related APIs.

The service should be presented as a structured security assessment performed with the client and development team.

High-level flow:

1. Understand the application and environment
2. Define assessment scope
3. Perform discovery and security testing
4. Validate findings
5. Assess impact and severity
6. Document evidence
7. Deliver actionable recommendations
8. Discuss findings with the client team
9. Support retesting when appropriate

Do not expose excessive internal methodology on the marketing website.

The website should explain the outcome and value rather than list every testing technique.

Primary outcomes for the client:

- Identified security risks
- Clear understanding of impact
- Prioritized findings
- Reproducible evidence
- Practical remediation guidance
- Structured security report
- Collaboration with the development team

# 21. Interaction Design (تصميم التفاعل)

Animations should be subtle.

Acceptable:

- Small fade-ins
- Element reveal
- Slight movement of technical background elements
- Button transitions
- Navigation transitions

Avoid:

- Heavy scroll effects
- Large parallax systems
- Constant motion
- Excessive glowing effects
- Animations that reduce readability

The site should remain fast.

---

# 22. Responsive Design (التصميم المتجاوب)

The website must work properly on:

- Mobile
- Tablet
- Laptop
- Large desktop screens

Mobile should not feel like a compressed desktop version.

Important content hierarchy should remain clear on small screens.

Technical visual elements may be simplified or hidden on mobile when necessary.

---

# 23. Accessibility (إمكانية الوصول)

Use:

- Semantic HTML
- Proper heading hierarchy
- Keyboard-accessible interactions
- Sufficient contrast
- Clear focus states
- Accessible buttons and links
- Meaningful alt text where relevant

Decorative graphics should not interfere with screen readers.

---

# 24. Performance (الأداء)

The site should be lightweight.

Avoid unnecessary dependencies.

Prefer:

- Static rendering when appropriate
- Optimized images
- SVG graphics
- Minimal client-side JavaScript
- Next.js Image optimization where appropriate

Performance should be considered part of the design.

# 30. Definition of Done (تعريف الإنجاز)

The first version is complete when:

1. cybrloop.com loads correctly.
2. The website clearly explains what CybrLoop is.
3. The primary service is understandable.
4. The CybrLoop approach is clear.
5. Visitors can easily contact the team.
6. LinkedIn and GitHub are linked.
7. Mobile and desktop layouts work correctly.
8. There are no fake claims or placeholder content.
9. The visual identity is consistent.
10. The site passes lint and production build.
11. Performance is reasonable.
12. The website feels ready to send to a real potential client.
